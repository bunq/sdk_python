⚠️ SDK Maintenance Notice This SDK is no longer actively maintained by bunq. Most developers now integrate directly with the bunq API,or build their own clients with LLM's. so our focus has shifted toward improving the API and documentation instead. The repository will remain available, but it will not receive updates, bug fixes, or new features from our side. If you choose to continue using it, you are free to fork the project and maintain your own version.

For more information, see: https://help.bunq.com/articles/sdk-deprecation
For full API documentation https://doc.bunq.com
